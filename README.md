# txt2epub

`txt2epub` 是一个用 Python 3 和 EbookLib 编写的命令行工具，用来把 TXT 小说或其他纯文本转换成带可点击目录的 EPUB 电子书。它支持转换单个文件，也支持批量转换一个文件夹里的 TXT。

## macOS 使用方法

在终端进入项目目录。macOS 上的示例使用 `python3`，依赖通过 `python3 -m pip` 安装。首次使用时，可以在虚拟环境中安装 EbookLib：

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install ebooklib
```

```bash
# 转换单个 TXT
python3 txt2epub.py "三体.txt"

# 指定书名、作者和封面
python3 txt2epub.py "三体.txt" -t "三体" -a "刘慈欣" -c "封面.jpg"

# 批量转换文件夹中的 TXT
python3 txt2epub.py "小说文件夹"
```

把示例中的文件名换成实际路径。默认用 TXT 文件名作为书名。批量转换只处理该文件夹直接包含的 TXT，可以用 `-a` 给整批文件设置同一作者。

生成的 EPUB 与原 TXT 位于同一个文件夹，文件名仅将扩展名换成 `.epub`。已有同名 EPUB 会被覆盖。终端会显示每个文件使用的编码和生成的章节数，例如 `✓ 三体.txt → 三体.epub（编码 gb18030，36 章）`。

## 脚本内部做了什么

1. **识别编码**。依次尝试 UTF-8（兼容 BOM，终端显示 `utf-8-sig`）、GB18030（兼容 GBK）、Big5（常用于繁体中文）和 UTF-16，采用第一个能成功解码的编码。如果全部失败，则用 UTF-8 读取并替换无法解码的字符。
2. **切分章节**。用正则表达式识别单独成行的标题，例如「第一章」「第2节」「第三回」「第一卷」「序章」「楔子」「番外」「后记」和 `Chapter 1`。首个标题之前的非空文字（如简介）会单独归为「前言」，并计入输出的章节数。
3. **排版**。正文的每个非空行转为一个段落，首行缩进两个字符宽度，章节标题居中。
4. **打包**。每章生成一个 XHTML 页面，EbookLib 将章节和可点击跳转的目录打包成 EPUB。

## 遇到问题时

- **章节数明显不对**。检查章节标题是否单独占一行、格式是否一致，再根据几行实际标题修改 [脚本开头的 `CHAPTER_RE`](txt2epub.py#L25-L33)。
- **一章都没识别到**。脚本会按每 300 行切分，生成「第1部分」「第2部分」等目录项。最后一部分可以少于 300 行。
